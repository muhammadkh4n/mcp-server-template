# Contributing

Thanks for your interest in contributing!

## Filing Issues

Please file bugs and feature requests in the [issue tracker](../../issues). Before opening a new issue, search existing ones to avoid duplicates. Include clear reproduction steps, expected vs. actual behavior, and your environment details.

## Submitting Changes

1. Fork the repo and create a feature branch from `main`.
2. Keep changes focused — one concern per pull request.
3. Run `npm run typecheck` and ensure existing tests pass.
4. Write a clear commit message explaining the *why*.
5. Open a PR against `main` with a concise summary.
